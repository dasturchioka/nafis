Nafis

A product design council. Three nuqta, three questions, one verdict. Calligraphers measure a letter in these dots. Nafis measures work the same way.

Select a dot or a name.

A measure, not a decoration

The name

"Nafis" means refined, finely finished. It comes from Alisher Navoi's Majolis un-nafois (1491), an early critical anthology that weighed the work of nearly 460 poets.

The nuqta

The rhombic dot a cut reed pen leaves on the page. Classical calligraphers set the height of every letter in nuqta, so the dot is a unit of proportion. Each one here keeps the pen's slant.

The three

One dot per council member. They sit offset, not in a line: three separate views of the same work, which together set the measure it has to reach.
